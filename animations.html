    Animated Simulations

    Interactive models, mathematical animations, and computational dynamics built using HTML/Canvas, Manim and Three.js.

    bash ~ Simulations/Animations/AR1
    AR(1) Interactive window
    html | js
    In the AR-model we have the Persistance parameter (φ) that tells us how significant the previous day is to us today. Adjusting φ shows us the various possibilities of how the consecutive values of the AR(1) Time series evolve over time.
    Begin Interaction ↗
    bash ~ Simulations/Animations/MA1
    MA(1) Interactive window
    html | js
    In the MA-models we take into account previous error with weightage θ along with the current error. At θ = \(0\) we have pure White noise. Slide the θ bar towards \(1\) to see the White noise evolving into a process with tendancy to have same sign for consecutive values and slide it to \(-1\) to see extreme oscillatory tendancies.

    bash ~ Simulations/Animations/AR2
    AR(2) Interactive window
    html | js
    In the AR(2) model we have values from previous two days affecting us today. To understand the relationship between \(Y_{t-2}\), \(Y_{t-1}\), and \(Y_{t}\) properly we need to plot all three.
    Begin Interaction ↗
    bash ~ Simulation/Animations/MA2
    MA(2) Interactive window
    html | js
    MA(2) models take into two previous errors with weight θ₁ and θ₂. This is also in \(3\)-D like the AR(2) Interactive window but note that the Covariance ellipsoid behave differently for MA and AR processes.
